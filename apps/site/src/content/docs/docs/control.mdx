title: Hotkeys
description: Change stats with programmable hotkeys, through OBS, with nothing leaving your machine.

Every input to Vellum, whether a click or a hotkey, becomes the same command, such as "add 1 to Hope". The HUD applies it, saves it and redraws. Commands are relative, so two quick presses always add up to two.

## Hotkeys

Hotkeys come from a small script you load into OBS once. It talks to the Vellum browser source directly: no WebSocket, no password, no network.

1. Download [`vellum-hotkeys.lua`](https://github.com/alxjrvs/vellum/blob/main/obs/vellum-hotkeys.lua).
2. In OBS, open **Tools → Scripts**, press **+** and pick the file.
3. Open **Settings → Hotkeys** and find the entries that start with **Vellum:**, such as _Vellum: Hope +1_.
4. Bind a key to each one you want.

The script offers Hope, HP, Stress, Armor and Fear up and down, a toggle for each condition, and next or previous [frame](/docs/frames/). OBS hotkeys work while OBS is in the background, so you can keep Discord in front.

## Buttons and macro pads

Anything that can send a key combination can drive Vellum: a spare keyboard, a macro pad, or a programmable button controller. Set each button to send the combination you bound to, say, _Vellum: Hope +1_, and label it.

A good starting layout is six buttons: Hope up, Hope down, mark HP, mark Stress, spend Armor, and toggle a condition.
