---
title: Hotkeys and Stream Deck
description: Change stats from the keyboard or a Stream Deck, through OBS, with nothing leaving your machine.
---

Every input to Vellum, whether a click, a hotkey or a Stream Deck key, becomes the same command, such as "add 1 to Hope". The HUD applies it, saves it and redraws. Commands are relative, so two quick presses always add up to two.

## Hotkeys

Hotkeys come from a small script you load into OBS once. It talks to the Vellum browser source directly: no WebSocket, no password, no network.

1. Download [`vellum-hotkeys.lua`](https://github.com/alxjrvs/vellum/blob/main/obs/vellum-hotkeys.lua).
2. In OBS, open **Tools → Scripts**, press **+** and pick the file.
3. Open **Settings → Hotkeys** and find the entries that start with **Vellum:**, such as _Vellum: Hope +1_.
4. Bind a key to each one you want.

The script offers Hope, HP, Stress, Armor and Fear up and down, a toggle for each condition, and next or previous [frame](/docs/frames/). OBS hotkeys work while OBS is in the background, so you can keep Discord in front.

## Stream Deck, with no plugin

Stream Deck's built-in **Hotkey** action can press the keys you bound above.

1. Drag a **Hotkey** action onto a key.
2. Set it to the same key combination you bound to, say, _Vellum: Hope +1_.
3. Label the key.

A good starting layout is six keys: Hope up, Hope down, mark HP, mark Stress, spend Armor, and toggle a condition.

## Stream Deck plugin

The Vellum plugin puts your live values on the keys: a Hope key shows 3/6 and its chits, a condition key lights up while the condition is on. On Stream Deck +, a dial turns a stat up and down and shows it on the touch strip.

1. Download [`vellum.streamDeckPlugin`](/downloads/vellum.streamDeckPlugin) and double-click it. The Stream Deck app installs it.
2. Find the **Vellum** category in the actions list and drag actions onto keys:
   - **Stat**: pick Hope, HP, Stress, Armor or Fear, and whether a press adds 1, takes 1 away, or only shows the value. Put it on a dial for Stream Deck +.
   - **Condition**: toggles Hidden, Restrained or Vulnerable.
   - **Frame**: steps to the next or previous [frame](/docs/frames/).
3. Keep Vellum open in OBS. The keys fill in within a second or two.

A key shows a dash while no HUD is listening, and pressing it shows a warning. The player HUD and the GM screen can both be open: the keys show whichever values each one reports, so a GM's Fear key works alongside a player's Hope key on the same deck.

### How it connects

The plugin listens on your computer's loopback address, `127.0.0.1`, which nothing outside your machine can reach. The Vellum page inside OBS connects to it, tells it what the HUD shows, and receives key presses. The plugin only answers pages from vellumhud.com, so another website open in your browser can't drive it. There's no OBS WebSocket to turn on and no password.

The page only tries to connect when it runs inside OBS. To try the keys in an ordinary browser tab, add `?deck=1` before the `#` in the address.

The plugin isn't signed or listed on the Elgato Marketplace yet, so the Stream Deck app may ask you to confirm the install.
