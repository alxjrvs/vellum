---
title: Troubleshooting
description: Fixes for the common ways a Vellum HUD fails to appear on camera.
---

## The HUD shows setup instead of my character

The browser source has no character yet: OBS keeps its own browser storage. Paste your **share link** into **Your Vellum link** in **Tools → Scripts → vellum.lua**, or into the source's URL if you set it up by hand.

## My character is blank in OBS

OBS has its own browser storage, separate from your normal browser. Use **Copy share link** in the app and paste that link into **Your Vellum link** in the Vellum script (or the source's URL). The link carries your character with it.

## The HUD is there but my face isn't

Check that **Camera** in the Vellum script names your webcam, then press **Set up Vellum** again. If you set up by hand, your webcam source must be **below** Vellum HUD in the sources list.

## My webcam isn't in the Camera list

Plug it in, close any app using it, and press **Refresh camera list**.

## Set up Vellum says a source already exists

You have a source called "Vellum HUD", "Vellum Camera" or "Vellum" that isn't the kind the script makes. Rename it and press **Set up Vellum** again.

## Discord doesn't list OBS Virtual Camera

Click **Start Virtual Camera** in OBS first, then restart Discord. On macOS, check that the OBS system extension is allowed in **System Settings → Privacy & Security**. On Linux, load `v4l2loopback`.

## Face tracking says it can't open the camera

OBS has to be started with `--enable-media-stream`. See [Face tracking](/docs/face-tracking/) for a per-OS shortcut. On Windows, only one app can use a camera at a time unless multi-app camera mode is on, so choose **Vellum draws the camera (face tracking)** under **Camera** in the Vellum script and press **Set up Vellum** again. That hides OBS's own webcam source.

## Something broke mid-session

Reload the browser source (right-click → **Refresh**). Your values are saved locally and come back.
